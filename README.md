# 🚀 AI Job Tracker Dashboard

A modern, production-quality AI-powered Job Tracker Dashboard built with React, TypeScript, Tailwind CSS, Vite, Supabase, and Recharts.

The application helps job seekers organize their job applications, monitor interview progress, visualize analytics, and leverage AI to prepare for interviews and improve resumes.

---

## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/your-username/ai-job-tracker-dashboard.git
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

### Build Project

```bash
npm run build
```
